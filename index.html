상촌중2 수학: 삼각형의 내심 탐구

점과 선을 터치하여 내심의 성질을 알아봅시다!

도구: 모눈 터치로 점 A, B, C 찍기 100%
💡 모눈 위 3곳을 터치하여 삼각형 ABC를 완성하세요. (마우스 휠/드래그로 화면 조절 가능)
1

삼각형 ABC 그리기

모눈종이에 세 개의 점을 터치하여 삼각형 ABC를 만들어보세요.

A, B, C 세 점을 차례로 터치하세요. (0/3)
2

세 내각의 이등분선 그리기

꼭짓점 A, B, C를 터치하여 각의 이등분선을 그려보세요.

먼저 삼각형 ABC를 완성하세요.
3

내심 I 찾기

세 각의 이등분선이 만나는 교점을 터치하여 내심 I를 찾아보세요.

먼저 세 각의 이등분선을 그려보세요.
4

내심에서 세 변에 수선 내리기

내심 I를 터치한 후 세 변 AB, BC, CA를 차례로 터치하세요.

내심 I를 먼저 찾아보세요.
5

수선의 길이 측정하기

파란색 수선 ID, IE, IF를 터치해 길이를 확인해보세요.

수선 ID (변 AB까지):미측정
수선 IE (변 BC까지):미측정
수선 IF (변 CA까지):미측정
ID, IE, IF를 모두 터치하세요.
💡 무엇을 발견했나요?
ID = IE = IF
내심은 삼각형의 세 변에서 같은 거리에 있습니다.
6

삼각형 변형 & 내심/외심 관찰

꼭짓점 A, B, C를 드래그하여 삼각형 모양을 자유롭게 바꿔보세요.

📐 삼각형 상태: -
점을 드래그하여 내심의 위치를 관찰하세요.
7

내심 개념 최종 정리

1. 내심의 정의: 삼각형 세 내각의 이등분선의 교점
2. 내심의 성질: 내심에서 세 변에 이르는 거리는 같다.
(ID = IE = IF = 내접원 반지름)

삼각형 종류내심의 위치
모든 삼각형항상 삼각형 내부
정삼각형내심과 외심 위치 일치!
